APK Checker 0.2.4：导入 APK，安装到手机或电视模拟器，并在独立窗口中运行。

## 本次更新

- 安装时选择手机或电视，软件库与桌面不再使用顶部模式 Tab 分类。
- 桌面统一展示已安装应用，卡片标注设备类型；同一个 APK 可分别安装到两种设备，打开和卸载绑定对应卡片。
- 新增电脑“输入文字”入口，支持用系统输入法写好文字后发送；两种模拟器同时运行时可明确选择目标。
- 使用模拟器原生窗口显示应用，支持原版麦动 2.1.8 的安全登录弹窗。
- APK 解析及必要通信组件随包提供；Android 引擎和系统镜像首次使用自动下载、校验并保存，无需安装 Android Studio、Java 或 aapt。

## 下载与安装

| 系统 | 安装包 |
| --- | --- |
| Apple Silicon Mac（M 系列） | `APK-Checker-0.2.4-mac-arm64.dmg` |
| Intel Mac | `APK-Checker-0.2.4-mac-x64.dmg` |
| Windows x64 | `APK-Checker-0.2.4-win-x64.exe` |

下载后可使用随附的 `SHA256SUMS.txt` 核对文件摘要。`release-provenance.json` 记录原生构建、源提交与发布提交，便于复查。

升级时先完全退出旧版，再替换或安装新客户端。首次准备模拟器需要联网、硬件虚拟化和足够磁盘空间；手机与电视系统可按需下载。使用说明见 [README](https://github.com/ecojust/apk-checker/blob/v0.2.4/README.md)。

## 已知限制

- macOS 安装包采用 ad-hoc 签名，已检查包内签名及原生客户端启动，尚未进行 Developer ID 签名或 Apple 公证。系统可能提示确认开发者，处理方式见 README。
- 原生窗口直接中文输入仍受模拟器限制。请先在 Android 输入框中取得键盘焦点（麦动可能需要 Tab／方向键），再使用桌面的“输入文字”；发送文字不会自动提交搜索或登录。
- 麦动的文字输入与登录框已在 Linux 手机／电视模拟器中验证；这不代表已完成 macOS／Windows 上的 KTV 播放、录音或性能验收。
